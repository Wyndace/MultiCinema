# MultiCinema

Сайт кинотеатра — хакатон-проект и портфолио-работа 2022 года.

**Figma:** [макет](https://www.figma.com/file/H89oPU6Jw54iPZAvmiIqKg/MultiCinema?node-id=0%3A1)
**Verstaem.online:** [проект](https://verstaem.online/projects/multi-cinema/)

## Структура сайта

- Шапка с навигацией (Фильмы, Треды, Новости)
- Популярные фильмы
- Форум / треды
- Новости

## Стек

- HTML / CSS / JS (сборка Gulp, WynGulp-шаблон)
- Минифицированные CSS/JS
